**EMBER & TIDE** is a 100% original, handcrafted 1v1 tactical elemental card duel game built with zero external dependencies (pure vanilla HTML, CSS, and ES-Module JavaScript) for make.fun's *"Make the best card game"* bounty.

## Game Features
- **4 Elemental Suits:** Ember (Flame / Attack), Tide (Droplet / Shield), Gale (Bolt / Tempo), and Stone (Hexagon / Counter).
- **Telegraphed Opponent Intent:** Read the opponent's face-up attack and counter it before the clash!
- **Dual Combo Systems:** Harmonic Pairs (same suit surge) and Elemental Reactions (cross-element combinations like Wildfire, Steam Veil, Glacier, and Shatter).
- **Procedural Audio:** Rich Web Audio API synthesizer for snaps, chimes, and impacts.
- **Full Controls:** Mouse and keyboard bindings (`1`–`5`, `Space`, `Enter`, `M`, `R`).
